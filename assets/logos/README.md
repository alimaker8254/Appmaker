# Club crest assets

The bundled SVG crests in this directory are sourced from the public
[JoseArroyave/football-logos](https://github.com/JoseArroyave/football-logos)
repository, whose README describes the collection as free to use for personal
and commercial projects.

Club names and crests are trademarks of their respective owners and are used
solely to identify the teams in this football-management game. Please review
the source repository's terms and each club's brand guidelines before any
public or commercial distribution.
