# ⚽ بازی مدیریت فوتبال (Football Manager Game)

نسخه تحت وب و موبایل (Landscape) بازی مدیریت فوتبال با تم نئونی.

## ویژگی‌ها
- صفحه انتخاب تیم (۱۵ تیم معروف)
- صفحه داشبورد باشگاه (لیگ، ارتقا، تاکتیک، خرید بازیکن و مربی)
- طراحی کاملاً افقی (Landscape) و ریسپانسیو
- لوگوهای طراحی شده با SVG (بدون نیاز به فایل عکس)

## نحوه اجرا در مرورگر
کافیست فایل `index.html` را باز کنید.

## تبدیل به APK
از طریق GitHub Actions و Capacitor این پروژه به اپلیکیشن اندروید تبدیل می‌شود.
