# Football Club Manager (Android prototype)

A landscape-first Godot 4 prototype for the football club management game.

## Included in this first build
- First-launch club selection (15 clubs)
- Home dashboard with €25,000 and 15 LP starting balance
- Settings screen with volume control, mute toggle, Telegram link and back button
- Saves selected club and settings locally on device
- Landscape Android orientation
- GitHub Actions workflow to export a debug APK

## Build
Push to `main` or manually run the **Build Android APK** workflow from the Actions tab. Download the `football-manager-debug-apk` artifact from the workflow run.

## Important
This is the first UI prototype. Club crests and decorative symbols are currently drawn as placeholders rather than official image assets. The supplied reference screenshots define the layout and visual direction; exact logo artwork and additional game systems will be added as source assets and later stages are provided.
