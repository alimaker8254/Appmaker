# Football Club Manager

A free, offline-first football club management game prototype built with Godot 4.

## Prototype 0.1
- Landscape Android layout
- Octagonal player cards without portraits
- Player ratings, positions and nationality
- Select a player to inspect details
- Formation selector
- Local lineup save on the device

## Build APK
The repository workflow **Build Android APK** can be started manually from GitHub Actions. The APK is uploaded as a workflow artifact.

This is an early UI prototype. Transfer market, match simulation, coins, coaches and league systems will be added in later versions.
